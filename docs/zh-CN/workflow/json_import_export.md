# 将文本导入 / 导出为 JSON

## 将文本导出为 JSON

使用 **文件 -> 导出文本 -> 原文文本** 或 **文件 -> 导出文本 -> 译文**，可以导出整个项目的原文或译文。如果刚刚导入了图片，请至少运行检测和 OCR 阶段，以填充项目中的文本。

## 从 JSON 导入文本

使用 **文件 -> 导入文本 -> 原文文本** 或 **文件 -> 导入文本 -> 译文**，可以导入现有的 JSON 文件。

## 使用导入 / 导出进行全文翻译

原文和译文使用相同的 JSON 格式，因此可以将一种类型的文件导出后作为另一种类型导入。也可以使用翻译服务或 LLM 翻译整个文件，从而利用完整文本上下文进行翻译。

首先运行检测和 OCR 阶段，然后导出原文。翻译 JSON 文件后导入译文，最后运行修复阶段。

## 翻译用 JSON 格式

- 页面编号从 1 开始，因此没有文本的页面可以省略。
- 文本项按照检测到的文本框顺序排列。
- 空字符串用于保留空原文或未翻译文本框的位置。
- 文本项数量不匹配的页面会被跳过。
- JSON 中没有对应条目的页面不会被修改。

示例：

```json
{
  "pages": [
    {
      "page": 1,
      "texts": [
        "第一个译文",
        "",
        "第三个译文"
      ]
    },
    {
      "page": 3,
      "texts": ["第 3 页的文本"]
    }
  ]
}
```

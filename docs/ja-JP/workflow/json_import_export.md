# テキストの JSON インポート / エクスポート

## テキストを JSON としてエクスポート

**ファイル -> テキストを書き出す -> ソーステキスト** または **ファイル -> テキストを書き出す -> 翻訳** を選択すると、プロジェクト全体の原文または翻訳文をエクスポートできます。画像を読み込んだ直後の場合は、テキスト情報を作成するため、少なくとも検出と OCR のステージを実行してください。

## テキストを JSON からインポート

**ファイル -> テキストを読み込む -> ソーステキスト** または **ファイル -> テキストを読み込む -> 翻訳** を選択すると、既存の JSON ファイルをインポートできます。

## 文脈を考慮した翻訳にインポート / エクスポートを使用する

原文と翻訳文は同じ JSON 形式を使用するため、一方の形式でエクスポートしたファイルをもう一方としてインポートできます。ファイル全体を翻訳サービスや LLM で翻訳すると、文章全体の文脈を考慮した翻訳を利用できます。

まず検出と OCR のステージを実行し、原文をエクスポートします。JSON ファイルを翻訳してから翻訳をインポートし、インペイントのステージを実行してください。

## 翻訳用 JSON 形式

- ページ番号は 1 から始まり、テキストのないページは省略できます。
- テキスト項目は検出されたテキストボックスの順番に並びます。
- 空の文字列は、空の原文または未翻訳のテキストボックスの位置を保持します。
- テキスト項目数が一致しないページはスキップされます。
- JSON にないページは変更されません。

例:

```json
{
  "pages": [
    {
      "page": 1,
      "texts": [
        "1つ目の翻訳テキスト",
        "",
        "3つ目の翻訳テキスト"
      ]
    },
    {
      "page": 3,
      "texts": ["3ページ目のテキスト"]
    }
  ]
}
```
